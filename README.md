## 🚀 Main Projects

### 1. RGB-IR Fusion based Pose Estimation Model

* **Description**: Designed a multimodal fusion framework to overcome the limitations of RGB-only models in low-light, occluded, and low-contrast environments.
* **Key Results**:

  * Improved end-to-end performance with **mAP increasing from 0.638 to 0.932** compared to the RGB baseline.
  * Reduced false positives from **535 to 11**, improving keypoint localization stability.
* **Keywords**: `PyTorch` `MobileNetV3` `RGB-IR Fusion` `AlphaPose`

### 2. Aspect-Based Sentiment Analysis via LLM Agents

* **Description**: Built a multi-agent system that dynamically extracts product features, called aspects, from unstructured reviews and evaluates sentiment for each aspect.
* **Key Points**:

  * Implemented an **Analyzer–Critic–Supervisor** workflow using **LangGraph** and traced agent execution with **LangSmith**.
  * Stored analysis results in **SQLite** and connected them to an interactive **Streamlit** dashboard.
* **Keywords**: `LangGraph` `LangChain` `SQLite` `Streamlit` `LLMOps`

### 3. Vision-based Autonomous Robot Perception & Path Estimation System

* **Description**: Developed a perception and path estimation system that combines RGB-D camera detection with depth information to estimate target positions in the robot driving frame.
* **Key Results**:

  * Improved field reliability, achieving a **navigation success rate of over 90%** in repeated closed-loop tests.
  * Won the **Grand Prize, Minister of Agriculture, Food and Rural Affairs Award 🥇**, and the **Excellence Prize, Administrator of Rural Development Administration Award 🥈**, at the Agricultural Robotics Competition.
* **Keywords**: `YOLOv5/v7` `RGB-D Camera` `OpenCV` `ROS` `Jetson` `Path Estimation`
